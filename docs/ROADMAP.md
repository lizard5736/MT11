# Дорожная карта Grip

Grip переносит на Windows 11 идеи macOS-приложения Vorssaint. Одни функции переносятся как есть, другие адаптируются под Windows, а часть на Windows не нужна. Работа идёт этапами. После каждого этапа выходит рабочий `Grip.exe`.

**Обозначения:** ✅ готово · 🔜 в плане · 🔄 адаптация под Windows · ⚠️ с оговорками · ❌ не делаем

## Этап 0. Каркас ✅
- ✅ Значок в трее, панель с вкладками или списком, компактный режим, порядок и видимость разделов
- ✅ Хаб функций: установка и удаление, три готовых набора, честные метки фоновой нагрузки
- ✅ Настройки с поиском, единый список горячих клавиш с проверкой конфликтов
- ✅ Страница «Доступы» вместо разрешений macOS: что работает в фоне, права администратора, где данные
- ✅ Темы «Графит» и светлая, русский и английский, экспорт и импорт настроек, мастер первого запуска
- ✅ Подсказки на экране (HUD), журнал ошибок, автозапуск

## Этап 1. Буфер и утилиты ✅
- ✅ История буфера: текст, ссылки, картинки, файлы, поиск, фильтры, закрепы, превью, Ctrl+1…9
- ✅ Автоочистка буфера: по таймеру, при блокировке, перед сном
- ✅ Вставка без форматирования с возвратом исходного содержимого
- ✅ Чистые ссылки: трекеры, редиректы, ссылки на поиск; вручную и автоматически
- ✅ Полка: встряхивание при перетаскивании, горячая клавиша, перетаскивание наружу
- ✅ Command Bar: приложения, окна, параметры Windows, действия, буфер, калькулятор, конвертер, эмодзи, скрипты, веб-поиск, исправление раскладки
- ✅ Радиальное меню: профили, подменю, выбор отпусканием, вызов кнопкой мыши
- ✅ Быстрые переключатели
- ✅ Не спать: таймер, «до времени», экран, закрытая крышка

## Этап 2. Звук и мониторинг 🔜
- 🔜 Микшер: громкость каждого приложения
- 🔜 Свой аудиовыход для приложения (как в Параметрах Windows, но в панели)
- 🔜 Переключение выходов горячей клавишей, тише при отключении наушников
- 🔜 Микрофон: выбор, уровень, выключение всех микрофонов одной клавишей
- 🔜 Процессор, видеокарта (NVIDIA и AMD — через их драйверы), память, диски, сеть, батарея, графики
- ⚠️ Температура процессора — через драйвер PawnIO (ставится отдельно, с правами администратора)
- 🔄 Показатели в трее вместо меню-бара
- 🔜 Предупреждения: нагрузка, перегрев, память, место на диске, батарея
- 🔜 Тест скорости сети, локальный IP, трафик за сессию

## Этап 3. Окна и ввод 🔜
- 🔜 Переключатель окон с живыми превью, поиском и фильтром по мониторам
- 🔜 Раскладка окон: половины, трети, шестые, углы, перенос между мониторами, возврат позиции
- 🔜 Защита от случайного Alt+F4 / Ctrl+Q / Ctrl+W
- 🔄 Полный выход для программ, которые прячутся в трей
- 🔜 Текстовые сниппеты с переменными
- 🔜 Плавная прокрутка, инверсия колеса, горизонтальная прокрутка, ускорение указателя, фокус за мышью
- 🔜 Кнопки мыши и жесты, фильтр двойных кликов, антидребезг клавиатуры, Super key
- 🔜 Исключения по приложениям для всех функций ввода

## Этап 4. Захват и медиа 🔜
- 🔜 Единый селектор: скриншот, запись, текст с экрана, пипетка
- 🔜 Скриншоты с аннотациями, обрезкой, закрашиванием, фонами, водяным знаком и закреплением поверх окон
- ⚠️ Длинный скриншот с прокруткой
- 🔜 Запись экрана с раздельными дорожками системы и микрофона, обрезка, зум, размытие, экспорт в видео и GIF
- 🔜 Текст с экрана через встроенный OCR Windows и QR-коды
- 🔜 Пипетка HEX, RGB, HSL, CSS; зеркало камеры
- 🔜 Медиаинструменты на FFmpeg: сжатие видео, конвертация картинок, водяные знаки, GIF

## Этап 5. Приложения 🔜
- 🔄 Менеджер winget вместо Homebrew: поиск, установка, удаление
- 🔄 Обновления winget и Microsoft Store одним списком
- 🔜 Очистка кэша, журналов и временных файлов, в том числе по расписанию
- 🔜 Загрузки Telegram и WhatsApp с правилами хранения
- 🔜 Деинсталлятор с поиском остатков в AppData и реестре
- 🔜 Порты: кто их занимает, завершение процесса

## Этап 6. Экраны и остальное 🔜
- 🔜 Яркость каждого монитора: встроенного — штатно, внешних — по DDC/CI, программное затемнение
- 🔜 Bluetooth на время сна
- 🔜 Быстрая панель любимых инструментов, блокнот с Markdown, режим уборки
- 🔜 Картинка из буфера сразу PNG-файлом в папку Проводника

## Не делаем

| Функция Vorssaint | Почему |
|---|---|
| Превью и клики по Dock | Панель задач Windows уже показывает превью, сворачивает по клику и перебирает окна по Ctrl+клику |
| Развернуть без нового Space | В Windows нет такой проблемы |
| Боковые кнопки «Назад/Вперёд» | В Windows работают из коробки |
| Средний клик тремя пальцами | Есть в настройках тачпада Windows |
| Ctrl+X / Ctrl+V для файлов, переименование по F2 | Уже есть в Проводнике |
| Установка из .dmg | На Windows нет .dmg |
| Запрет запуска Apple Music | Проблема есть только на Mac |
| Дополнительная яркость XDR | Особенность железа MacBook Pro |
| Dynamic Island и его расширения | Решили не делать |
| Управление вентиляторами | Зависит от материнской платы, есть риск перегрева |
| Громкость выше 100% | Нужен системный аудиокомпонент |
| Временные ссылки на скриншоты | Нужен облачный хостинг |
